สถานะ: อยู่ระหว่างพัฒนาและพิสูจน์ข้อมูล
มีข้อมูลบัญชี LINE OA จากเจ้าของโครงการแล้ว ส่วนความพร้อมตอบกลับและความแม่นของพยากรณ์ยังไม่ได้ยืนยันในเอกสารนี้

ปัญหา

พยากรณ์ภาพรวมระดับจังหวัดอาจไม่ตอบคำถามว่า “บริเวณที่ฉันอยู่ อีก 3 ชั่วโมงฝนจะเป็นอย่างไร” ขณะที่การอ่านแผนที่เรดาร์ต้องเข้าใจตำแหน่ง เวลา และความหมายของสี

แนวทางแก้ไข

ออกแบบ chatbot ให้สอบถามแนวโน้มฝนตามพื้นที่ที่สนใจ โดยดึงพยากรณ์ตามพิกัดจาก Open-Meteo แล้วสรุปเป็นภาษาที่เข้าใจง่าย พร้อมระบุพื้นที่ ช่วงเวลา และแหล่งข้อมูล เริ่มทดลองที่ทุ่งสองห้อง กรุงเทพฯ

คุณค่าที่คาดหวัง

ช่วยประชาชนเข้าถึงพยากรณ์ที่เจาะจงกว่าภาพรวมจังหวัด และเข้าใจแนวโน้มฝนโดยไม่จำเป็นต้องอ่านแผนที่เป็น คุณค่านี้ยังต้องทดสอบกับผู้ใช้จริง

ข้อจำกัดที่เปิดเผย

  • API ให้พยากรณ์ตามพิกัด แต่ความละเอียดจริงขึ้นกับกริดของโมเดล หลายแขวงอาจใช้ข้อมูลกริดเดียวกัน
  • พยากรณ์จากโมเดลไม่ใช่การยืนยันฝนที่ตกจริง ณ จุดนั้น
  • ยังไม่มีผลทดสอบยืนยันว่าแม่นกว่าพยากรณ์ทั่วไปหรือผู้ที่อ่านเรดาร์เป็น
  • ต้องตรวจโมเดล กริด ความสดของข้อมูล และการเชื่อมต่อจริงก่อนอ้างความสามารถระดับแขวง

การพิสูจน์ผลลัพธ์ขั้นถัดไป

ความถูกต้อง: เปรียบเทียบพยากรณ์ที่บันทึกไว้ล่วงหน้ากับข้อมูลตรวจวัดในพื้นที่ แยกฝนที่พลาดและฝนที่คาดว่าจะตกแต่ไม่ตก

ความเข้าใจ: ทดสอบว่าผู้ใช้ตอบคำถามเกี่ยวกับพื้นที่ ช่วงเวลา และความหมายของพยากรณ์ได้ถูกต้องและรวดเร็วขึ้นหรือไม่

English overview

A chatbot designed to make location-based rain forecasts easier to understand, starting with Thung Song Hong, Bangkok. It translates coordinate-based Open-Meteo forecasts into concise answers with location, time and source information. Expected benefits remain to be tested. Grid resolution limits neighbourhood detail; model forecasts do not confirm observed rain. No superior forecast accuracy or live bot readiness is claimed.

หลักฐานและแหล่งอ้างอิง
Open-Meteo Forecast API documentation — coordinate-based forecasts and model-dependent resolution.
Met Office: Radar products — radar observations and short-range forecasting.
