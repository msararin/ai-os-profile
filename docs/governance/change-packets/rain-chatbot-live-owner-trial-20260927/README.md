## Claim boundary

Allowed:

- `LIVE PILOT`;
- `OWNER-CONFIRMED OPERATIONAL`;
- `OWNER-TESTED USEFULNESS: avoided manual radar interpretation`.

Still not allowed without additional evidence:

- more accurate than province-level forecasts, maps, radar or another service;
- accurate at khwaeng level merely because the user can select a khwaeng;
- benefit established across a broader group of local residents;
- feature-by-feature independent validation where no retained receipt is attached;
- language parity or forecast-versus-observation accuracy as independently verified.
